# 8列×6行、1フレーム48文字版

元映像を8列×6行に分割し、48マスそれぞれを最も近いUnicodeグリフに置き換えます。候補辞書と照合方法は12文字版と共通で、空白は候補に含めません。暗いマスにも可視グリフが選ばれます。

```powershell
.venv\Scripts\python -m badapple_unicode grid --grid 8x6 --output output/grid-8x6 --backend native --encoder h264_nvenc
```

CUDA検索ライブラリがない環境では `--backend faiss`、NVIDIAエンコーダーがない環境では `--encoder libx264` を使用できます。CUDA版のビルド手順は [GRID-4X3.md](GRID-4X3.md) にあります。

各マスの細部を保つため、元映像は640×480（1マス80×80）で読み取ります。セルを32×24へ縮小してぼかし、41万510候補を全探索します。表示には元フォントの輪郭を使います。

表示は48文字、元映像の小窓、固定位置のフレーム番号です。右側に「セル番号・字形・U+コード」の一覧を2列×24段で表示します。番号は左上から行優先で1〜48、一覧は左列が1〜24、右列が25〜48です。字形は選択された元フォントから縦横比を保って描画し、結合文字も独立した枠内に表示します。音声、元の30000/1001fpsを維持します。

## 出力

`output/grid-8x6/` に保存します。

- `badapple-unicode-8x6.mp4`：2560×1920、全編・音声付き
- `thumbnail.png`：1:54.01の、3人のシルエットが並ぶフレーム
- `characters.txt`：1フレームにつき48コードポイントを一行に記録。左上から行優先
- `frames.jsonl`：48文字、コードポイント、グリフID、距離、フレーム時刻
- `matches.npz`：再出力用の検索結果
- `summary.json` / `timing.json` / `verification.json`：条件、タイミング、完成動画の確認結果

文字列はUTF-8で保存し、Unicode正規化は行いません。結合文字や補助面の文字もあるので、通常のテキストエディター上では見た目のセル数が48に揃わない場合があります。動画は48マスに固定して描画します。

完成版は6,955フレーム、333,840文字選択、2560×1920です。関連テスト39件、全編デコード、音声と映像の長さ、全行48コードポイント・空白なしを確認しています。選ばれた文字は3,818種類でした。
